# 流时 · Orbit Clock

一个由本地时间驱动的动态时钟实验，提供 **2D SVG** 和 **3D WebGL** 两个独立网页。两版都可以在“不规则”和“规则”两种模式间切换：一版让刻度沿轨道流动，另一版让指针沿固定刻度转动。

## 网页成品

| 版本 | 页面 | 特点 |
| --- | --- | --- |
| 2D | [`2d/index.html`](2d/index.html) | SVG 绘制、轻量响应式布局、平滑形态转场 |
| 3D | [`3d/index.html`](3d/index.html) | WebGL 金属质感、可交互视角、内嵌渲染库与字形 |

GitHub 的文件页面会显示 HTML 源码。想实际体验时，下载对应的 `index.html`，再按下方说明用浏览器打开。

## 两种表盘模式

### 不规则

小时显示在中央金色圆轨，亮铜色分钟轨道延伸至右下，银白色秒钟轨道沿左侧展开。指针固定，刻度与数字沿各自的闭合路径流动。

### 规则

小时、分钟、秒钟从内向外组成金色、亮铜色、银白色三圈。刻度固定，传统腕表式指针连续转动。

切换模式时，轨道在约 1.8 秒内平滑变形；动画过程中可以再次切换方向。两种模式都根据设备本地时间连续更新，并适配桌面和手机屏幕。

## 3D 版操作

| 操作 | 效果 |
| --- | --- |
| 鼠标拖动 / 单指拖动 | 连续旋转观察角度 |
| 鼠标滚轮 | 放大或缩小 |
| 双指开合 | 高灵敏缩放，范围为 0.75–2 倍 |
| 方向键 | 调整观察角度 |
| `+` / `-` | 缩放 |
| `R` 或双击画面 | 复位视角与缩放 |
| “沉浸” / `Esc` | 隐藏界面 / 退出沉浸 |
| “降低动态” | 减少动画并直接切换模式；默认遵循系统的降低动态偏好 |

3D 版需要支持 **WebGL 2** 的现代浏览器。页面不依赖 CDN、在线字体或远程模型；打开后时钟在本机读取系统时间。

## 本地运行

最简单的方式是下载 `2d/index.html` 或 `3d/index.html`，直接用现代浏览器打开。两个页面都是自包含的单文件网页。

也可以在仓库根目录启动本机预览服务：

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

然后访问：

- 2D：<http://127.0.0.1:8766/2d/>
- 3D：<http://127.0.0.1:8766/3d/>

结束预览时，在运行服务的终端按 `Ctrl+C`。
