# 流时 · Orbit Clock

一个以本地时间驱动的动态时钟，包含独立的 2D SVG 版和 3D WebGL 版。两版都提供“不规则”和“规则”两种模式。

## 网页

- [2D 网页](2d/index.html)：SVG 绘制，文件自包含，可下载后直接用现代浏览器打开。
- [3D 网页](3d/index.html)：Three.js/WebGL 2 渲染，库和数字字形已内嵌，可下载后离线打开；需要支持 WebGL 2 的浏览器。

页面内容仅在浏览器本地读取系统时间，不请求外部授时服务。

## 表盘模式

- **不规则**：小时显示在内侧金色圆轨，分钟和秒钟沿外侧曲线轨道显示。2D 版固定指针、刻度沿轨道流动；3D 版提供可交互视角。
- **规则**：小时、分钟、秒钟由内向外组成三圈，刻度固定、指针连续转动。切换带有平滑形态转场。

3D 版支持鼠标或触屏旋转视角、缩放、复位、沉浸显示和降低动态效果；双指缩放采用高灵敏响应，缩放范围为 0.75–2 倍。
